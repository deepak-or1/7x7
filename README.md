# Seven by Seven

A trail map of San Francisco and the whole Bay Area: 166 places in six regions (the City 38, Marin 25, East Bay 39, Peninsula 25, South Bay 15, North Bay 24), from Cloverdale to Gilroy, each cut into the sections locals actually name. Walk them, log the restaurants, bars and views you find, and keep the flags.

It is a static site: no build step, no framework.

## Run it

Open `index.html` through any static server (opening the file directly works for everything except place search and the web manifest):

```
python3 -m http.server 8123
```

## Host it

The repo ships a GitHub Pages workflow (`.github/workflows/pages.yml`). Once, in the repository settings, set **Pages → Source** to **GitHub Actions**. Every push to `main` then deploys; the workflow can also be run by hand from the Actions tab. A hosted copy is what lets the "Where am I?" button use the phone's location, which browsers block inside an embedded frame.

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | the shell |
| `css/app.css` | all styling, light and dark |
| `js/map.js` | the canvas map: camera, gestures with inertia, terrain cache, labels, landmarks, hit testing |
| `js/app.js` | state, the Bay Area › region › place › section › spot hierarchy, logbook views, logging, storage |
| `js/sheet.js` | the phone bottom sheet |
| `js/geom.js` | projection, point-in-polygon, the Voronoi cut that sections a place |
| `js/glyph.js` | renderer for the 2.5D landmark glyphs |
| `js/places.js` | place search (Photon, OpenStreetMap data) |
| `js/sync.js`, `js/sync-config.js` | the shared logbook on the hosted site |
| `js/photos.js` | photos on spots, sections and places (hosted site): downscale, cache, the strip and the lightbox; stored beside the log at `logs/<key>-ph` |
| `data/geo.js` | boundaries and the projected canvas (generated by `tools/geo-build.js`; do not edit by hand) |
| `data/info.js` | editorial text per place |
| `data/subareas.js` | sections inside each place (built from `data/subareas_{sf,bay,south,eastbay,north}.json`): a seed point plus a line, drawn as Voronoi cells clipped to the boundary |
| `data/landmarks.js` | the landmark glyphs |
| `tools/build.js` | merges `data/subareas_*.json` into `data/subareas.js` and writes `dist/artifact.html`, the single-file page for the Claude artifact |

## Data

On the hosted site the log is shared: one record per secret key in a Firebase Realtime Database (`js/sync-config.js` holds the database URL, `js/sync.js` talks to it over REST with no SDK), with the key carried in the `?log=` part of the link you bookmark and a copy kept in `localStorage`. Open a link with a key on another phone and that phone joins the same log. The database rules allow reads and writes only below a key, never a listing. Inside the Claude artifact the log is one shared document for everyone the artifact is shared with. Boundaries: SF Planning Department (San Francisco neighborhoods); everywhere else in the nine Bay Area counties, US Census TIGERweb generalized (1:500k, shoreline-clipped) incorporated places and census-designated places, with Census counties for the land between places and the coast. High points: Mapzen/AWS terrarium elevation tiles (zoom 12). Place search: Photon, © OpenStreetMap contributors.
